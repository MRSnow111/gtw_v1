# Инвентаризация экранов GTW (для дизайна)

Полное описание страниц, полей и состояний. Дополняет design.md, визуальный референс — forest dashboard (3 плавающие glass-панели).

## 1. `/` — Вход
- Фон: лес + световые лучи (общий).
- Бейдж-пилюля: точка + «GTW — AI-агент нового поколения».
- Карточка glass-strong ~420px: лист-тайл 64px, «GTW», «Войдите в свой аккаунт».
- Поля: Логин (autofocus), Пароль (masked + Показать/Скрыть).
- Кнопка «Войти»: loading-спиннер + блок полей; disabled при пустых.
- Ошибки инлайн: «Заполните все поля» / «Неверный логин или пароль» / «Сервер недоступен…».
- Состояния: default / loading / error / успех→`/chat`.

## 2. Каркас `/chat*`
Три панели: сайдбар 290 · центр flex · артефакты 276 (<1280 скрыть). <768: сайдбар = drawer.

### Сайдбар
- Шапка: лист + «GTW», кнопка темы (v1 disabled-декор).
- «Новый чат» (full-width пилюля, `+`).
- Поиск (фильтр по заголовку).
- Список: группы Сегодня/На этой неделе/Ранее. Строка: иконка-тип, заголовок (ellipsis), время/превью, hover «⋯» (Переименовать inline / Удалить с подтверждением). Активный: подложка + неоновый бар 3px. Генерация: спиннер вместо времени. Пусто: «Ничего не найдено».
- Футер: Настройки · Выйти.

### Артефакты (§6 design.md)
Шапка: «Артефакты» + счётчик + external-open. Список: иконка типа, имя, размер/время. Просмотр: код (номера строк, копировать) / изображение (fullsize по клику) / прочее (метаданные + скачать). Пусто: inbox + «Здесь будут результаты работы агента». Skeleton/retry.

## 3. `/chat` — Welcome
- Шапка центра: WS-пилюля (точка + «Подключено к агенту» / «Переподключение…» / «Нет соединения») + круглые кнопки копировать/развернуть.
- Центр: лист-тайл 80px, H1 «Чем займёмся?», подзаголовок «Ваш персональный AI-агент готов к работе», сетка 2×2: Написать код / Работа с сервером / Анализ данных / Работа с файлами (иконка-тайл + заголовок + подпись).

## 4. `/chat/[id]` — Активный чат
Единица — ход агента (не пузырь):
1. Thinking: «Думает…» → «Думал 4.2с» (схлопнуть).
2. Tool-строки: иконка + «terminal: …» + ⏳/✅/❌; клик = аргументы + вывод (30 строк + «Показать всё»); ошибка: красная рамка, вывод сразу.
3. Markdown-ответ: код-блоки с копированием; стриминг-курсор.
4. Approval (inline, жёлтая рамка): «Агент просит разрешения выполнить…», полный код, [Подтвердить]/[Отклонить] + комментарий; итог → схлопнутая строка «✅ Разрешено / ❌ Отклонено»; TTL → «срок истёк».
5. Служебная строка: время, токены in/out, длительность; hover: копировать / регенерировать.

Ход юзера: мятный пузырь справа, чипи вложений, галочка ⏳/✓, hover: Копировать / Изменить и отправить.
Состояния ленты: skeleton истории (6), ошибка+retry, «остановлено», пустой чат, 404 чата («Чат не найден» + «На главную»).

## 5. Композер
- Лупа + textarea автораст (1→7 строк), плейсхолдер «Напишите сообщение…», Enter/Shift+Enter.
- `/команды`: дропдаун при вводе `/`, список с сервера, стрелки/Tab/Enter.
- Чипи вложений над полем: иконка, имя, размер, ✕, прогресс; failed = красный + retry.
- Низ: скрепка, загрузка; справа круглая мятная ↑ (glow) ↔ красный ■ stop.
- Офлайн: жёлтая плашка «Соединение потеряно. N в очереди».

## 6. Настройки (модалка)
Профиль (имя display-only) · Соединение (WS URL, статус, «Переподключиться») · Интерфейс (тема disabled «в разработке») · футер «Выйти». Без Save — immediate + тосты.

## 7. Оверлеи
Сессия истекла (тост + редирект, черновик сохраняется) · подтверждение удаления · inline-переименование · fullsize изображений (Esc) · мобилка: гамбургер → drawer, артефактов нет.
